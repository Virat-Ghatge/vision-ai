Dassi bundles these unmodified ffmpeg.wasm packages:

@ffmpeg/ffmpeg 0.12.15: MIT (wrapper-MIT.txt).
@ffmpeg/core 0.12.10: GPL-2.0-or-later (core-GPL-2.0.txt).
The wrapper's MIT license does not replace the core's license.

Upstream release containing both package versions:
https://github.com/ffmpegwasm/ffmpeg.wasm/releases/tag/v12.15
Corresponding source and build recipes (including external codec versions):
https://github.com/ffmpegwasm/ffmpeg.wasm/tree/v12.15
Source archive:
https://github.com/ffmpegwasm/ffmpeg.wasm/archive/refs/tags/v12.15.tar.gz
FFmpeg source used by this build:
https://github.com/FFmpeg/FFmpeg/tree/n5.1.4

The single-thread ESM core and its WASM are copied from the pinned npm package
at build time. Dassi's proprietary source-file banner does not apply to these
third-party assets. See upstream Dockerfile/build scripts for linked components
and their respective licenses.
